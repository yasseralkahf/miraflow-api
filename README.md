# MiraFlow API

MiraFlow is a project and issue management REST API built with Laravel.
It is designed to demonstrate production-oriented backend engineering,
automated testing, API documentation, and cloud deployment.

## Planned Features

- Authentication and user management
- Organizations, memberships, and role-based access control
- Project and issue management
- Comments and activity history
- Filtering, sorting, and pagination
- Automated tests and static analysis
- Docker-based development environment
- Continuous integration with GitHub Actions
- API documentation and cloud deployment

## Technology Stack

- PHP
- Laravel
- PostgreSQL
- Redis
- Docker
- PHPUnit or Pest
- GitHub Actions
